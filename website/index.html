NightsEdge

About

NightsEdge is a fork of Firefox maintained by RadioactiveHydra / EdwardJXLi. It tracks the latest stable Firefox releases while providing an independently maintained alternative to Mozilla’s official binaries for Linux, Windows, and macOS.

The best way to describe NightsEdge is that it is “un-Mozilla’d Firefox” with Firefox Nightly branding (hence the name). Telemetry, crash reporting, studies, Pocket, sponsored content, and recommendation services are all disabled by default, while staying close to upstream Firefox.

The current version is: hydra-152.0

Differences

  • Uses Firefox Nightly branding (hence the name).
  • Keeps theme backgrounds in the top toolbar by default, with an option to extend them across the vertical-tabs sidebar.
  • Slightly modifies in-browser text.
  • Keeps the About dialog available from the Help menu on macOS.
  • Packages the parenthesized NightsEdge display name correctly in macOS disk images.
  • Loads NightsEdge's default preferences after Firefox's defaults.
  • Includes NightsEdge's enterprise policies in non-Mozilla builds.
  • Removes the standalone telemetry ping sender from the build.
